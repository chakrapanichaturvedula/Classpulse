# Saved report CSV downloads

Open Reports, choose a completed activity, then Download CSV. The web download is generated locally from the same teacher-only saved result document; no new SQL or permissions are needed. Native builds show a browser-download hint until native file sharing is added.

The current export follows the faculty's Socrative example: Student Name, Student ID, Total Score (%), Number of Correct Answers, then one column per question with its full prompt as the heading. MC answers use A. Yes; true/false answers use T/F; short answers retain original spelling and line breaks. Unanswered cells are blank. Quick questions use names, IDs and question columns only, without invented grades.

All snapshot roster students remain listed. Students who neither joined nor answered have blank scores and are excluded from Class Scoring. Joined/answering students' unanswered questions earn zero, so incomplete submissions receive their earned score out of the full quiz points. Total Score remains weighted by configured question points; with equal points it matches correct-answer percentage. Number of Correct Answers counts true server grades independently of points. Pending manual grades show Pending rather than a fabricated zero or final score. Class Scoring contains the average percentage, average number correct, and percent correct for each question. Pending total/count values are excluded from their respective averages; a question with any pending participant grade has a blank class percentage. Zero-point totals have blank percentages. The live screen's average continues to cover only complete, fully graded quizzes.

Downloads include the full roster and answers regardless of the on-screen visibility switches. CSV uses UTF-8 with a BOM for Excel, CRLF row separators, doubled quotes, and quoted cells for commas/newlines. Formula-looking text receives a protective apostrophe. Numeric-only IDs are preserved in the CSV text; import student_id as Text in Excel to preserve leading zeros. The filename includes the room, title and session ID, distinguishing repeated runs. College ERP import column requirements may need a separate export mapping.
