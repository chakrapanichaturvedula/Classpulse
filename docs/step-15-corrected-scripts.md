# Step 15: Individual corrected scripts

Implemented locally, 13 October 2026. Requires migration 202610130001_student_scripts.sql after migrations 1-10. No tables or row-security settings are changed. This read-only, authenticated teacher RPC checks session ownership, ended quiz status and saved roster membership before joining the immutable session version to private answer keys. It returns exactly one student's responses, preserving historical names, IDs and quiz contents. The room label follows the current room name, matching saved reports.

## Faculty test
Run the setup in a new Supabase SQL Editor query. Refresh localhost, open Reports, choose an ended quiz, click Corrected scripts and download a participating student's PDF. Verify Student ID, responses, correct answers, per-question marks and total. Run the separate privacy check as the SQL Editor administrator; its fictional fixtures roll back.

PDFs use existing awarded marks. Unanswered questions count as zero in an ended attempt; incomplete attempts are labelled. Non-participants cannot download a script. Pending submitted answers block finalized PDFs until teacher marking is implemented in the next phase. Quick polls/word clouds have no corrected scripts. Faculty can download all ready scripts in one ZIP, with progress and cancellation. Non-participants and pending students are excluded explicitly. Bulk export checks every returned student/session identity, rechecks grading and aborts on failures without issuing a partial archive. Email delivery is a separate upcoming phase: each student must receive only their own script, never the faculty ZIP. No additional SQL migration is required for bulk download.
